# BabelQueue — `.github`

This repository holds **organization-wide defaults** for the
[BabelQueue](https://github.com/BabelQueue) organization. GitHub picks these up
automatically across every repo that doesn't define its own.

- [`profile/README.md`](profile/README.md) — the public org profile rendered at
  **<https://github.com/BabelQueue>**
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute to any BabelQueue repo
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community standards
- [`SECURITY.md`](SECURITY.md) — how to report a vulnerability
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) — default PR template
- [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) — default bug-report / feature-request forms

> **BabelQueue** — *Polyglot Queues, Simplified.* See the profile above or
> [babelqueue.com](https://babelqueue.com).
